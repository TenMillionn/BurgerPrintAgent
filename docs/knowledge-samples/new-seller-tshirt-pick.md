# How to recommend a starter t-shirt for a new POD seller

Use this whenever a seller is new, unsure what to sell, or asks for a "good t-shirt to start with" for a given market.

## What to ask first (only if missing)
1. Which **market** are they selling to? (US, EU, UK...). If they don't say, assume **US**.
2. Their **budget** (max base cost per shirt). If they don't say, assume **under $8**.

Do not ask more than these two things — if you already have them, go straight to the recommendation.

## How to pick
1. Search the catalog for t-shirts in that market within budget.
2. Prefer products that have **many color options** (more designs) and support **DTG and DTF** printing.
3. Favor the **lowest base cost** and a fast factory.

## How to answer
- Show **exactly 2–3 options** in a compact table: product, base cost (from), cheapest factory, number of colors, print methods.
- Then give **one clear "Starter pick ⭐"** line recommending a single product and one sentence on why (cheapest + most colors).
- Keep it short. Do not dump the whole catalog or add unrelated advice.
