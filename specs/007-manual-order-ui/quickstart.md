# Quickstart

To begin implementing the 007-manual-order-ui feature:

1. **Frontend**: Navigate to `frontend/src/components/` and create the `ManualOrderWizard` directory.
2. **Backend**: Navigate to `backend/src/orders/` (or `burgerprints/`) and implement the `/calculate-cost` and `/create` endpoints according to the data model.
3. **Tasks**: Use `/speckit-tasks` to break down the implementation into trackable tasks.
